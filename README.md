# WC Name Your Price - Buy Now Button

## Quickstart

This is a developmental repo, but for now, it is not complex enough to require a build process, but does use one for translations and autoupdates.

|[Download latest release](https://github.com/backcourt/wc-nyp-buy-now/releases/latest)|

### What's This?

Experimental mini-extension for [WooCommerce Name Your Price](https://woocommerce.com/products/name-your-price/) that adds a new button next to the add to cart button. When clicked this button will add the product to the cart for a pre-defined price.

![A sample product named 'Simple NYP' with the image of a record. There is a price input field. There is an add to cart button and next to it, there is a button labeled 'Buy now for $113.' ](https://github.com/user-attachments/assets/f132cc25-e254-4b04-be10-4e840e187b97)

### Setup

A new field, called "Buy now price" will be added to the product data metabox.

![a text input titled "buy now price" appears below another text input titled "Maximum price"](https://github.com/user-attachments/assets/17b090ee-c226-4e69-844a-5ce955b59d44)

>**Warning**

1. This is provided _as is_ and does not receive priority support.
2. Please test thoroughly before using in production.
3. Requires Name Your Price 3.6.0+ and WooCommerce 9.0+
4. Limited only to NYP's simple supported product types (not variations)
